# Koda: assistente de voz para Windows

Instalador oficial do **Koda**, da Kodaru Soluções Tecnológicas.

## Como instalar

1. Baixe o instalador mais recente: **[Koda-Setup.exe](https://github.com/Kodarusistemas/koda-instalador/releases/latest/download/Koda-Setup.exe)**
2. Abra o arquivo e siga as telas. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Na primeira tela do Koda, digite **o mesmo e-mail usado na compra** e clique em Ativar.

Cada compra ativa o Koda em até 2 computadores.

## Precisa de ajuda?

Abra o Koda e use a aba **Suporte**, ou escreva para **kodarusistemas@gmail.com** ou no Direct do Instagram **@kodarusistemas**.

Este repositório guarda apenas o instalador. O Koda é um produto pago: a ativação exige o e-mail de uma compra válida.
